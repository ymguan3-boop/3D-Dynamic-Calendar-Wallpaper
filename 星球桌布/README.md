# 星球桌布

創作人 官毅明

一款給 [Lively Wallpaper](https://github.com/rocksdanister/lively) 使用的 3D 動態桌布：宇宙場景中，畫面右側有一顆會自轉的小星球，上面住著星球旅人與各種會自己互動的居民；畫面正中間是月曆，可以新增、刪除行程。

> 本作品為個人原創，與任何既有出版品或角色無關。

## 畫面內容
- **小星球**：星球旅人、玻璃罩裡的玫瑰、冒煙的火山、會自己點亮與熄滅的路燈、猴麵包樹、小椅子，星球持續自轉。
- **宇宙背景**：流動的星雲與銀河帶、會閃爍的星星；帶環行星、條紋氣態巨行星、冰藍星球、綠色雲層星球與小月亮緩慢自轉，平常微微發光，偶爾散發能量波與光點。
- **流星**：每隔幾秒劃過，偶爾一場流星雨。
- **月曆**：正中間以月份顯示，當天金框標示，行程以彩色標籤顯示。

## 居民互動
- 可新增狐狸、綿羊、兔子、小蛇、小鳥、蝴蝶（最多 60 隻），牠們會散步、發呆、睡覺、相遇打招呼
- 綿羊和兔子會吃猴麵包樹苗；看到小蛇會逃跑；狐狸會走到星球旅人身邊坐下；小鳥成群飛，有時停在星球旅人頭上唱歌；狐狸和兔子會追蝴蝶
- 星球旅人會揮手打招呼、呼喚遠處的居民、摸摸坐到身邊的居民、把靠近玫瑰的綿羊趕走、幫玫瑰澆水、抬頭看星星
- 點一下居民或星球旅人，他們會回應你

## 下載與安裝
1. 安裝 **Lively Wallpaper**（免費、開源）：Microsoft Store 或 [GitHub](https://github.com/rocksdanister/lively/releases)。
2. 下載 [`download/星球桌布-Lively.zip`](download/星球桌布-Lively.zip)。
3. 開啟 Lively，把 zip 拖進視窗（或按「+」選擇 zip），套用即成為桌布。
4. Lively「設定 → 桌布 → 互動 → 桌布輸入」：選「滑鼠」可點按桌面面板與居民；要在桌面面板直接打字輸入行程請選「鍵盤」。
5. 多螢幕：使用 Lively 內建的顯示設定（主螢幕、副螢幕、複製到所有螢幕等）。

桌布包只有網頁與 Lively 設定檔，不含執行檔或腳本；three.js 已內嵌，離線也能使用。

## 使用方式
- 桌面右下角「✦ 星球居民及行事曆」面板：
  - **星球居民**：新增居民、流星雨、移除一隻、清空、自轉速度、流星頻率。
  - **行事曆**：‹ › 選擇桌面顯示的月份（「回到本月」改回自動跟隨當月）；填日期、時間（可不填）、內容、標籤顏色後「加入行程」；清單中按 ✕ 刪除。
- 在 Lively 對桌布按「自訂」也能調整速度、新增居民、切換月份，並以文字框加入行程（不需開啟鍵盤輸入）。
- 居民與行事曆存在 Lively 的瀏覽器儲存中。

## 自行建置
需要 [Node.js](https://nodejs.org/)。

```
node build.cjs
```

會在 `dist/` 產生 `index.html`（內嵌 three.js）、`LivelyInfo.json`、`LivelyProperties.json`，把這三個檔案壓成 zip 即可匯入 Lively。

本機預覽：`node serve.cjs`，再開 http://localhost:5199/index.html（網頁開發版會從 CDN 載入 three.js）。網址加上 `?close` 可近拍檢視星球。
