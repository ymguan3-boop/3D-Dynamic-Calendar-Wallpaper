# 3D 動態行事曆桌布

創作人 官毅明

適用於 Windows 10／11 的 3D 動態桌布。小公主和居民住在會自轉的小星球上，桌面月曆可管理行程和匯出 Excel，桌布可顯示在主螢幕、副螢幕或兩個螢幕。

## 安裝與啟動

1. 下載上方所選版本的 ZIP。若打開 GitHub 檔案頁，按 **Download raw file**。
2. 在 Windows 檔案總管對 ZIP 按右鍵，選 **解壓縮全部**。
3. 開啟解壓縮後的資料夾，雙擊 **安裝星球桌布.cmd**。安裝完成後，桌布會顯示在桌面圖示後方。
4. 開啟桌面捷徑 **星球居民及行事曆管理**，或點擊桌布右下角的木紋按鈕。AI Lite 版可點擊小公主或按 `Ctrl+Alt+P` 對話。第一次使用語音時請允許麥克風。

需有 Microsoft Edge。AI Lite 可在本機離線使用，選用 Groq AI 時才需要設定 Groq API 金鑰。更新時下載同版新 ZIP 後重新執行安裝程式。停止或解除安裝可從開始功能表的「星球桌布」資料夾操作。
