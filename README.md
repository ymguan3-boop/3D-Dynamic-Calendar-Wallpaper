# 3D 動態行事曆桌布

創作人 官毅明

結合 3D 動態場景與月曆的桌布作品集，使用 [Lively Wallpaper](https://github.com/rocksdanister/lively) 顯示在 Windows 桌面上。每件作品都只有網頁與 Lively 設定檔，不含執行檔或腳本。

## 作品
| 作品 | 說明 | 下載 |
| --- | --- | --- |
| [星球桌布](星球桌布/) | 宇宙中自轉的小星球，星球旅人與會自己互動的居民；正中間月曆可新增、刪除行程；背景星球會自轉並散發能量 | [星球桌布-Lively.zip](星球桌布/download/星球桌布-Lively.zip) |

## 安裝方式（所有作品通用）
1. 安裝 **Lively Wallpaper**（免費、開源）：Microsoft Store 或 [GitHub Releases](https://github.com/rocksdanister/lively/releases)。
2. 下載作品的 zip，拖進 Lively 視窗後套用。
3. 需要點按或輸入時，到 Lively「設定 → 桌布 → 互動 → 桌布輸入」選擇「滑鼠」或「鍵盤」。
